# MySpoti releases

Downloads for the GPL-3.0 MySpoti fork at https://github.com/TheDarkRoby/myspoti, based on https://github.com/kota-zo/myspoti.

Each release includes signed x64/x32 APKs and the matching complete GPL-3.0 source archive. Stable and preview builds share the same package and signing key. Preview updates can be enabled in Settings > App.
